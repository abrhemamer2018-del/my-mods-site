# موقع التعريبات — دليل الاستخدام

موقع ثابت (Static) مبني بـ [Astro](https://astro.build) لعرض تعريبات الألعاب والمودات العربية.

## تشغيل الموقع على جهازك

افتح الطرفية (Terminal) داخل مجلد المشروع ثم:

```bash
npm install        # مرة واحدة فقط (أو بعد نقل المشروع لجهاز جديد)
npm run dev        # تشغيل للتطوير على http://localhost:4321 (يتحدث تلقائياً عند الحفظ)
```

لتجربة النسخة النهائية مع البحث:

```bash
npm run build      # يبني الموقع في مجلد dist
npm run preview    # يعرض النسخة المبنية
```

> البحث لا يعمل في وضع `npm run dev`، فقط بعد `build` ثم `preview`.

## أين أعدّل ماذا؟

| أريد أن... | الملف |
|---|---|
| أغيّر اسم الموقع، الوصف، رابط الدعم، روابط التواصل، عدد التحميلات | `src/config.ts` |
| أغيّر الألوان والخطوط | أول الملف `src/styles/global.css` |
| أغيّر الشعار والأيقونة | `public/logo.svg` و `public/favicon.svg` |
| أضيف تعريباً | `src/content/translations/` (انظر بالأسفل) |
| أضيف مقالاً أو درساً | `src/content/articles/` |
| أضع رابط الدومين الحقيقي | `astro.config.mjs` ← `site` |

## إضافة تعريب جديد

1. انسخ المجلد `templates/translation` إلى `src/content/translations/` وسمّه باسم اللعبة بالإنجليزية (أحرف صغيرة وشرطات)، مثل `silent-hill-2`.
2. ضع داخله صورة الغلاف `cover.jpg` (يفضّل بمقاس 1280×720) وأي لقطات شاشة.
3. عدّل ملف `index.md` حسب التعليقات الموجودة فيه.
4. احفظ، وسيظهر التعريب في الموقع مباشرة (في وضع `dev`).

**تحديث تعريب:** غيّر `version` و `updatedDate` وأضف عنصراً جديداً في أعلى `changelog`. سيظهر تلقائياً في قسم "آخر التحديثات" بالرئيسية.

## إضافة مقال أو درس

أنشئ ملفاً جديداً في `src/content/articles/` مثل `my-article.md`:

```md
---
title: عنوان المقال
description: وصف قصير
date: 2026-10-01
kind: lesson   # lesson = درس | article = مقال
tags: [دروس]
---

نص المقال هنا بصيغة Markdown.
```

## الصور

- استخدم JPG أو PNG أو WebP. الموقع يضغط الصور ويصغّرها تلقائياً عند البناء.
- الصور الحالية في الأمثلة مؤقتة؛ احذف مجلدات الأمثلة عندما تضيف تعريباتك.

## ملاحظات قانونية

وزّع ملفات الباتش/التعريب فقط، ولا ترفع ملفات اللعبة الأصلية أو ملفات ROM.

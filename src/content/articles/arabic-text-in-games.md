أغلب محركات الألعاب لا تدعم **تشكيل الحروف العربية** (Arabic Shaping) ولا **الاتجاه من اليمين لليسار** (RTL). لذلك يظهر النص بحروف منفصلة ومعكوسة.

## الحل

1. **تشكيل الحروف:** تحويل كل حرف إلى الشكل المناسب لموقعه (أول الكلمة، وسطها، آخرها، منفرد) باستخدام أحرف Unicode Presentation Forms.
2. **عكس النص:** قلب ترتيب الأحرف حتى يُعرض من اليمين لليسار.
3. **الخط:** إضافة خط يحتوي على هذه الأشكال إلى ملفات اللعبة.

## مثال بلغة Python

```python
import arabic_reshaper
from bidi.algorithm import get_display

text = "مرحباً بالعالم"
reshaped = arabic_reshaper.reshape(text)
print(get_display(reshaped))
```

في الدروس القادمة سنشرح كيف نستخرج نصوص اللعبة ونعيد إدخالها.
